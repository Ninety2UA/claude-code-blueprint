Executive Summary

Fourteen repos and tools were evaluated through direct source code inspection: architecture analysis, prompt engineering review, skill/workflow content audit, release history tracking, and community metrics assessment. Each was classified by its actual function rather than its marketing. Five additional repos were analyzed post-v2.0 (claude-mem, claude-squad, OpenCLI, Anthropic skill-creator, GSD-2) — three deliberately rejected with documented rationale.

Author's Pick

Superpowers would be my first install. It changes how the agent thinks, not just what it does. The anti-rationalization architecture and TDD enforcement produce measurably better code. Then add Claude Skills as a complementary expertise layer. For long projects, add GSD. For UI-heavy work, add UI/UX Pro Max. For role-based workflows with QA and design audit, add gstack. The key insight: these tools occupy different layers and the best setup combines 2–3, not all 9.

Features wave-based parallel execution, goal-backward verification, Nyquist test validation, and atomic git commits. Now accompanied by GSD-2."
Context engineering solves a real problem (context rot)
Full project lifecycle coverage (32 commands)
Wave-based parallel execution with dependency awareness
Goal-backward verification (checks results, not claims)
Steep learning curve (32 commands to discover)
Rapid churn risk (22 releases in 2 weeks, 258 open issues)

Honest Reality Check

No tool is perfect. Here's what each project needs to address honestly.

  • Superpowers — No parallel execution. Prescriptive workflow can frustrate experienced devs who want to skip phases.
  • GSD — 32 commands is overwhelming. Rapid release cadence (22 in 2 weeks) risks instability.
  • gstack — Rails-centric patterns. No built-in orchestration — requires external Conductor for parallelism. Monolithic skill files.
  • Compound Eng. — 48KB swarm skill strains context. Rails/Ruby bias in review agents. Single maintainer risk.
  • Claude Skills — Pre-1.0 maturity. No execution engine. Solo contributor.
  • Ralphy — --dangerously-skip-permissions is concerning. Zero quality gates. Bad PRD = bad code fast.
  • Everything CC — Kitchen sink risk. Hook debugging is opaque. Node.js dependency.
  • Plugins Plus Skills — Quality varies across 315 plugins. Discoverability is a real challenge.
  • UI/UX Pro Max — Single domain. CSV backend can't scale.

07

Combining Tools

The best setup combines 2–3 tools from different layers, not all 9.

Safe Combinations
Superpowers + Claude Skills — methodology + domain expertise (different layers, no conflict)
GSD + Claude Skills — orchestration + expertise (complementary)
gstack + Superpowers — role-based QA/review + methodology (some overlap in review, but different angles)
Superpowers + UI/UX Pro Max — methodology + design (orthogonal domains)
Risky Combinations
Superpowers + GSD — competing workflow philosophies. GSD's commands may conflict with SP's skill triggers.
Everything CC + Compound Eng. — both are comprehensive. Combined context footprint is excessive.
gstack + GSD — different orchestration models. gstack's monolithic skills vs GSD's lean orchestrator.
